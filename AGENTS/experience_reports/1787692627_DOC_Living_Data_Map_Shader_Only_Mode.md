# Documentation Report

**Date:** 2026-08-25
**Title:** Living Data Map shader-only mode

## Overview

Added a reversible full-page presentation mode to the first-person shader
viewport generated by `turing/src/compiler/abstract_ui_div_map.py`.

## Changes

- Added a `Shader only` button to the viewport.
- Added a `body.shader-only` presentation state that hides the mast, inspector,
  entity layer, document districts, regions, and viewport instrumentation while
  sizing the shader canvas to the full browser page.
- Kept a small `Exit shader only` control over the canvas and made Escape exit
  the mode.
- Regenerated `turing/docs/generated/abstract_ui_object_map.html`.
- Added focused regression assertions to `tests/test_abstract_ui_div_map.py`.
- Moved the normal-page button from the lower-right over the placement panel to
  reserved space at the top-right of the viewport header; shader-only mode
  still places its exit control at the lower-right of the full-page canvas.
- Refined that placement by putting the button in the right telemetry column,
  directly beneath its readouts with the same four-pixel top spacing as the
  shader dropdown. Entering shader-only mode reparents the button onto the
  viewport so it remains available after the header is hidden.

## Verification

- The new regression and the nearby viewport composition regression pass:
  `2 passed`.
- The complete generated page's inline JavaScript parses with Node, and its
