## Method and limits

Canonical checkouts were inventoried without fetching. Linked worktrees were
deduplicated by their common Git directory. Captured ref IDs and canonical HEADs
were supplied to `git log --stdin`; no reflog, unreachable-object, archive or
full nested-submodule reconstruction was attempted. Every listed commit object
was verified in its owning database and every listed parent is accounted for.

Source comparisons and selected diffs support the central lineage. Existing
Alpha/Kakarot and pre-Kakarot documents are treated as dated analyses pending a
separate re-audit. Commit subjects are not runtime validation. No compiler,
simulation, physical device, service deployment, or site publish was run here.

Turing's captured Pages source at `353b16c3` is a large living-data-map demo;
its README and the outer generated compiler gallery are distinct. The owner
now envisions cross-linked repository sites and an interactive/static total
README. That is direction, not an implemented site network or a naming-rights
finding.

A separate authorized licensing change establishes first-party MIT across the
five central repos, with third-party exclusions. The outer history snapshot
predates it; the forensic doc records the newer commit IDs separately. This
history work did not edit license files.
