# Studio atlas object studies and compound camera

The current Studio REST ink atlas adapter accepts a saved full scene/photo
profile and uploads glyph/token OBJ subjects. It does not yet expose an
account-facing bake service or execute the existing display-scene planner's
part/rotating-condition requests. Continue from
`1794463029_DOC_Studio_Atlas_Profile_And_Fixed8_Tick_Receipt.md` and
`spectral-analyzer/docs/STUDIO_INK_ATLAS_REST_BAKER.md`.

Use the existing scene planner and account-scoped Studio photo asset contract
for sequential views of an authored object, retaining the text route. Keep
the compound-camera transfer-table preview, native T5 lens traversal, and
Studio sensor path distinct until the actual lens traversal and comparable
photo evidence are integrated. HTML layout and texture-map packaging are
future consumers of the same object/scene bake contract.
